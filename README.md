# Expense Tracker App

## 📱 Overview
Expense Tracker is an Android application that helps users manage their daily expenses by recording income and expenses. The app provides a clean interface to track spending and view financial records.

## ✨ Features
- User Authentication (Firebase)
- Add Income & Expense
- Edit & Delete Transactions
- View Expense History
- Dashboard with Total Balance
- RecyclerView for Transaction List
- MVVM Architecture
- Material Design UI

## 🛠 Tech Stack
- Kotlin
- XML
- Firebase Authentication
- Cloud Firestore
- MVVM
- RecyclerView
- View Binding
- Material Components

## 🚀 Installation

1. Clone the repository
2. Open in Android Studio
3. Sync Gradle
4. Add Firebase configuration (`google-services.json`)
5. Run the application
